# Memory & Quirks: GeoCrisis

- Web Audio API procedural: sintetizador de bipes táticos, alarmes de emergência e fanfarra de vitória para garantir áudio sem depender de arquivos externos ou quebrar políticas de autoplay do navegador.
- Babylon.js 3D Earth: renderização em canvas integrado sob o dashboard tático, com rotação suave e pontos marcadores pulsantes por tipo de catástrofe.
- PDR Fidelity:
  - Recursos iniciais exatamente iguais ao item 7 do PDR: 1000 Finanças, 100 População Protegida, 50 Sustentabilidade, 3 Vidas, 0 XP.
  - Cartas de Crise, Decisão, Evento e Conhecimento.
  - Classificação final conforme item 11 (Líder Global, Gestor Expert, Gestor em Desenvolvimento, Gestor Iniciante).
  - Seção 14 (Avaliação de Aprendizagem Antes / Depois) com geração de gráfico interativo e exportação de dados para feiras de ciências.
